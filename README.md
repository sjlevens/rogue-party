# Rogue Party: support pages

The public support and privacy pages for the Rogue Party mobile game, served with GitHub Pages at
https://sjlevens.github.io/rogue-party/.

- `index.html`: support and common questions
- `privacy/index.html`: privacy policy

This repository holds only these static pages. It contains no game code, assets or secrets.

Questions or problems with the game: [open an issue](https://github.com/sjlevens/rogue-party/issues).
